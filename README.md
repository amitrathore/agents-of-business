# Agents of Business

The website for [www.agentsofbusiness.com](https://www.agentsofbusiness.com), redesigned for millennial, Gen Z, and Gen Alpha audiences.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build:pages
```

The static site is exported to `out/` and automatically deployed to GitHub Pages from `main`.
